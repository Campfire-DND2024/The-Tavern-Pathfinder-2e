# The Tavern

A free Pathfinder Second Edition campaign companion for players and Game Masters: character sheets, dice, encounters, maps and handouts, synced between your group's phones.

**Open the app:** https://campfire-dnd2024.github.io/The-Tavern-Pathfinder-2e/

## Installing it on a phone

- **iPhone:** open the link in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** open the link in Chrome and tap **Install app**, or install The Tavern APK.

The web app and the APK sign in to the same accounts and sync the same campaigns.

## Updating

Upload the new files over the old ones. Players get the update the next time they open the app.
